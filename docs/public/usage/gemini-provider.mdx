# Gemini provider

The `gemini` generation provider sends each generation request to the Google Gemini API.

## Get an API key

1. Open [Google AI Studio API keys](https://aistudio.google.com/app/apikey) and sign in.
2. Select **Create API key** and choose a Google Cloud project.
3. Copy the key.

## Configure the provider

Choose one of these methods:

- Run `npx memsmith install` and choose Gemini. The installer saves the key and the provider.
- Select Gemini on the dashboard **Settings** tab. Run `memsmith status` to print the dashboard address.
- Edit `~/.memsmith/settings.json`:

```json
{
  "MEMSMITH_SERVER_PROVIDER": "gemini",
  "MEMSMITH_GEMINI_API_KEY": "your-api-key-here",
  "MEMSMITH_SERVER_MODEL": "gemini-2.5-flash"
}
```

Run `memsmith restart` after you edit the file. A provider that you choose on the dashboard overrides the file.

| Setting | Default | Description |
|---------|---------|-------------|
| `MEMSMITH_SERVER_PROVIDER` | `claude` | Set to `gemini` to use this provider. |
| `MEMSMITH_GEMINI_API_KEY` | none | Your Gemini API key. |
| `MEMSMITH_SERVER_MODEL` | `gemini-2.5-flash` when unset | The Gemini model ID. |

MemSmith resolves the API key in this order: the `MEMSMITH_GEMINI_API_KEY` environment variable, the value in `settings.json`, then the `GEMINI_API_KEY` environment variable.

Run `memsmith doctor` to confirm that the **Generation** check reports `gemini · API key present`. The check doesn't call the API.

## Request format

MemSmith sends one `generateContent` request for each generation job to `https://generativelanguage.googleapis.com/v1/models/<model>:generateContent`, with `temperature` of `0.3` and `maxOutputTokens` of `4096`. MemSmith doesn't throttle requests, so rate limits come from your Google Cloud project and plan.

## Errors and local backup

MemSmith classifies a failed request as transient, rate limited, quota exhausted, an invalid key, a parse error, or unrecoverable, and logs the failure. An HTTP 400 response that isn't a quota error is unrecoverable.

By default, MemSmith also falls back to a local Ollama model after any failed request. For 5 minutes, jobs go to the local model first, and then MemSmith tries Gemini again. Set `MEMSMITH_SERVER_FALLBACK` to `none` to turn the backup off. For details, see [Configuration](/configuration).
