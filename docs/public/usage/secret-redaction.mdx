# Secret redaction

MemSmith replaces known secret patterns with a marker before it stores captured content, sends it to a generation provider, or writes it to a log. Redaction needs no tags and no setting. No setting turns it off.

Redaction is pattern-based. A secret in a format that MemSmith doesn't recognize is stored as captured. Wrap that secret in `<private>` tags. For details, see [Private tags and secret redaction](/usage/private-tags).

## Marker format

A redacted value becomes `[REDACTED:<kind>]`. MemSmith keeps the text around the value, so the name of a variable and the shape of a command stay readable:

```text
ANTHROPIC_API_KEY=[REDACTED:anthropic_key]
Authorization: Bearer [REDACTED:bearer_token]
postgres://app_user:[REDACTED:password]@db.internal:5432/app
{"db_password": "[REDACTED:password]"}
```

The kind is one of these values:

| Kind | What it replaces |
|------|------------------|
| `anthropic_key`, `openai_key`, `stripe_key`, `github_token`, `gitlab_token`, `huggingface_token`, `google_api_key`, `aws_access_key_id`, `slack_token`, `npm_token` | Provider keys and tokens, found by their prefix and length. |
| `jwt` | A JSON Web Token with three dot-separated segments. |
| `bearer_token` | The value after `Bearer`. |
| `authorization` | The value of an `Authorization` header or field, including the `Basic`, `Token`, `Digest`, `Negotiate`, and `NTLM` schemes. |
| `private_key` | A PEM or PGP private key block. |
| `password` | A password in a connection string, a `.netrc` entry, an npm `_password` entry, or a value under a name that ends in `password`, `passwd`, or `pass`. |
| `key`, `token`, `secret` | The value under a name that ends in `key`, `token`, or `secret`, and `key_base`, such as `SECRET_KEY_BASE`. |
| `circular`, `unserializable` | A value that MemSmith can't copy safely, such as an object that contains itself. MemSmith replaces the whole value so that it never stores unredacted content. |

Redaction runs again until the text stops changing, up to three passes, so running it twice gives the same result as running it once. Text shorter than 8 characters is never changed.

## Where redaction runs

Redaction runs at each of these points. Later points cover content that an earlier point missed, such as an event from an older hook or a third-party client.

| Where | What MemSmith redacts |
|-------|-----------------------|
| The hook, before it sends a request | Tool input and tool responses, event payloads, session metadata, the prompt that the record-intent backstop sends, and the content and metadata of notes and observations. |
| The hook, before it writes the capture spool | Each event that the hook buffers while the server is unreachable. |
| The server, before it stores | Event payloads, session metadata, the content and metadata of notes and observations written through `/v1/memories`, and the prompt for record-intent. |
| The server, before it calls a generation provider | Every event payload in the prompt. This runs for Claude, Gemini, OpenRouter, and Ollama. |
| The logger | Every log line that MemSmith writes to `~/.memsmith/logs`, including the tool summaries in the lines. |

MemSmith also strips `<private>` tags and the text inside them at the same points.

MemSmith redacts content that it captures after you update to version 13.14.0. Memories, events, and log lines that exist from before the update stay as they are.

## What MemSmith redacts

The patterns fall into these groups.

**Prefixed tokens.** MemSmith matches a prefix, an allowed character set, and a minimum length. A match inside a longer word is left alone.

| Provider | Prefixes |
|----------|----------|
| Anthropic | `sk-ant-` |
| OpenAI | `sk-` and `sk-proj-`, when the value has both letters and digits |
| Stripe | `sk_live_`, `sk_test_`, `rk_live_`, `rk_test_` |
| GitHub | `ghp_`, `gho_`, `ghu_`, `ghs_`, `ghr_`, `github_pat_` |
| GitLab | `glpat-` |
| Hugging Face | `hf_`, when the value has both letters and digits |
| Google | `AIza` |
| AWS | `AKIA` and `ASIA` access key IDs |
| Slack | `xoxb-`, `xoxp-`, and the other `xox` types, when the value has a digit |
| npm | `npm_` |

**Structured secrets.** MemSmith also redacts JWTs, bearer tokens, `Authorization` values, private key blocks, and passwords in connection strings such as `scheme://user:password@host`. A private key block ends at its `END` line. If the `END` line is missing, the block ends at the first quote or blank line, so a truncated key doesn't remove the text after it.

**Values under secret names.** MemSmith redacts the value of a field, variable, or command-line flag when the name ends in `key`, `token`, `secret`, `password`, `passwd`, or `pass`, in assignments such as `NAME=value`, `name: value`, `"name": "value"`, and `--name value`. A JSON object key counts as a name, so `{ "API_KEY": "..." }` is redacted as a whole.

For `pass`, the name must be `pass` alone, or `pass` after `_`, `.`, or `-`, such as `SMTP_PASS`. A camelCase name such as `dbPass` counts when the value has at least 6 characters and at least one that isn't a letter.

## What MemSmith doesn't redact

A rule that is too broad removes useful memory, so MemSmith checks the value and the name before it redacts. It leaves these alone:

- **Placeholders and empty values**, such as `<your-key>`, `${VAR}`, `$VAR`, `{{ key }}`, `%KEY%`, `xxxx`, a value that starts with `your-` or `your_`, and words such as `changeme`, `example`, `null`, and `string`.
- **Code and file references**, such as `process.env.API_KEY`, `/etc/ssl/server.key`, and `certs/server.key`.
- **Values that are too short or too plain**, such as an all-digit value under a `key` or `token` name, or a bare value under a `password` name that has fewer than 4 characters or only letters.
- **UI labels.** A quoted value of three or more plain words that starts with a capital letter or ends with `.`, `?`, `!`, or `:`, such as `"Forgot your login details?"`. A passphrase of lowercase words, such as `correct horse battery staple`, is redacted.
- **Identifier names**, such as a bare `key`, `idempotencyKey`, `cacheKey`, `PUBLIC_KEY`, `nextToken`, `pageToken`, `max_tokens`, and `renderPass`.
- **A function call.** A bare value that is followed by `(`, such as `token = getToken()`, is code.
- **Text that already has a marker.** MemSmith doesn't redact a value that starts with `[REDACTED:`.

### Test results after `pass:`

Version 13.15.0 fixed a false positive: the word `pass` in test output. When the name is the bare word `pass`, followed by a colon, MemSmith keeps an unquoted count, fraction, or percentage, so a line stays readable:

```text
Stack CI first pass: 12/27 green
```

MemSmith treats these values as results: a whole number up to 4 digits, a fraction such as `12/27`, and a percentage up to three digits, such as `98%` or `98.5%`. A value with other characters is still a password:

```text
pass: hunter22x      ->  pass: [REDACTED:password]
pass=1234            ->  pass=[REDACTED:password]
"pass": "..."        ->  "pass": "[REDACTED:password]"
```

The exception applies only to a colon. An equals sign, a quoted value, and a longer number are all redacted.

## Handle false positives

If MemSmith redacts a value that isn't a secret, the stored memory has a marker where the value was. The marker doesn't affect your session, because Claude sees the full text during the conversation.

To reduce false positives in your own content:

- Rename the field so that it doesn't end in `key`, `token`, `secret`, `password`, or `pass`, when the value is an identifier.
- Use a placeholder in documentation and examples, such as `<your-key>` or `${API_KEY}`.
- Write a count or percentage after `pass:` for test results, not after `pass=`.

To keep a secret in an unrecognized format out of memory, wrap it in `<private>` tags.

## Compare redaction with other controls

MemSmith has four ways to keep content out of memory. Each one works at a different level.

| Control | What it affects | How you turn it on |
|---------|-----------------|--------------------|
| Secret redaction | Known secret patterns, replaced with a marker. The surrounding text is kept. | Always on. |
| [`<private>` tags](/usage/private-tags) | Text that you wrap in tags, removed completely. | You wrap the text. |
| [Incognito mode](/usage/incognito) | Tool-use capture for one session. | `/incognito` command. |
| [Read-only mode](/usage/read-only-mode) | All capture and all memory writes for a session. | `MEMSMITH_ACCESS=read`. |

Use redaction for known formats, `<private>` tags for one passage, incognito mode to pause tool-use capture in a session, and read-only mode to stop recording entirely.
