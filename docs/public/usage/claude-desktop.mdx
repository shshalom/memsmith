</Note>

## Overview

Claude Desktop can search your MemSmith memory through the MemSmith MCP server. You can look up past sessions, decisions, and notes directly from Claude Desktop conversations.

## Prerequisites

1. MemSmith is installed. If it isn't, run `npx memsmith install`.
2. The MemSmith server is running. To check, run:

   ```bash
   npx memsmith status
   ```

   It prints the server address, by default `http://127.0.0.1:<38877 + your user ID % 100>`. If the server isn't running, run `npx memsmith start`.

## Configure the MCP server

Add the MemSmith MCP server to your Claude Desktop configuration:

<Tabs>
  <Tab title="macOS">
    Edit `~/Library/Application Support/Claude/claude_desktop_config.json`:

    ```json
    {
      "mcpServers": {
        "memsmith": {
          "command": "node",
          "args": [
            "/Users/YOUR_USERNAME/.claude/plugins/marketplaces/shshalom/plugin/scripts/mcp-server.cjs"
          ]
        }
      }
    }
    ```
  </Tab>
  <Tab title="Windows">
    Edit `%APPDATA%\Claude\claude_desktop_config.json`:

    ```json
    {
      "mcpServers": {
        "memsmith": {
          "command": "node",
          "args": [
            "C:\\Users\\YOUR_USERNAME\\.claude\\plugins\\marketplaces\\shshalom\\plugin\\scripts\\mcp-server.cjs"
          ]
        }
      }
    }
    ```
  </Tab>
</Tabs>

<Warning>
Replace `YOUR_USERNAME` with your username. Then close and reopen Claude Desktop.
</Warning>

## Usage

Ask about past work in plain language:

```
"What did we do last session?"
"Did we fix this bug before?"
"How did we implement authentication?"
"What decisions did we make about the API?"
```

## Available MCP tools

| Tool | Description |
|------|-------------|
| `observation_search` | Searches your observations and returns a ranked index: id, date, type, title, and a short snippet. |
| `observation_get` | Returns the full records for ids from `observation_search`. |
| `observation_context` | Returns the full bodies of the top few observations for a query. |
| `note_add` | Saves a note when you ask Claude to remember something. |

Search first, then request context for only the few results that matter. This keeps token use low.

## Troubleshooting

### The MCP server doesn't connect

1. Run `npx memsmith status` and confirm that the server is running.
2. Confirm that the path to `mcp-server.cjs` in your configuration exists.
3. Check the Claude Desktop logs:

<Tabs>
  <Tab title="macOS">
    ```bash
    tail -f ~/Library/Logs/Claude/claude.log
    ```
  </Tab>
  <Tab title="Windows">
    Check `%APPDATA%\Claude\logs\`.
  </Tab>
</Tabs>

### Searches return no results

1. Open the **Dashboard** address that `npx memsmith status` prints, and confirm that observations exist.
2. Run `npx memsmith doctor` to check the install.
