# Incognito mode

Incognito mode is a per-session switch that stops MemSmith from recording tool use. You control it with a prompt command.

## Turn it on or off

Type one of these commands as a prompt in Claude Code:

| Command | Result |
|---------|--------|
| `/incognito on` | Turns incognito mode on and replies `Incognito ON — nothing from this session will be recorded.` |
| `/incognito off` | Turns it off and replies `Incognito OFF — recording resumed.` |
| `/incognito` | Toggles the current state. |

The command is case-insensitive. The `session-init` hook handles it before any other processing and replies with a message that Claude Code adds as context. The command has no effect in a folder that you excluded from tracking.

MemSmith keeps the state in `~/.memsmith/incognito/<session-id>.json`, one file per session, with the file mode `0600`. The file holds whether incognito is on and a turn counter. If MemSmith can't read the file, the session isn't incognito, so capture continues. MemSmith never deletes these files.

## What incognito mode suppresses

Verified in the source, incognito mode suppresses one thing: the `observation` hook, which records tool use on `PostToolUse`. While a session is incognito, that hook returns before it sends anything, and no tool input or tool response leaves the machine.

Incognito mode doesn't stop these captures, because none of these hooks check the incognito state:

- **Your prompts.** The `session-init` hook starts or updates the server session with your prompt in the session metadata on every prompt except the `/incognito` command itself and a reminder turn.
- **The end-of-turn summary.** The `Stop` hook still sends the last assistant message for summary generation.
- **File edits** that the `file-edit` handler records.
- **The record-intent backstop**, which can save a "remember this" request as a note.

If you need the whole session to stay out of memory, use [read-only mode](/usage/read-only-mode) with `MEMSMITH_ACCESS=read`. Read-only mode skips prompts, tool use, file edits, and summaries.

## Reminder cadence

While incognito mode is on, MemSmith adds `🔒 still incognito — not recording` as context on every Nth prompt. N is the value of `MEMSMITH_INCOGNITO_REMINDER_TURNS`, which defaults to `10`. A value that isn't a positive integer uses `10`. The counter is per session, and it counts only prompts that you send while incognito mode is on. A reminder turn skips the rest of the prompt handling, including session start and capture for that prompt.

`MEMSMITH_INCOGNITO_REMINDER_TURNS` is also a server setting named `incognitoReminderTurns`. For the full list of settings, see [Settings reference](/settings-reference).
