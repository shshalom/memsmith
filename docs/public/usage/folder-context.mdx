# Folder context files

MemSmith doesn't generate per-folder `CLAUDE.md` files automatically in the current release. Nothing in the hooks or the server calls the folder generator, so `MEMSMITH_FOLDER_CLAUDEMD_ENABLED` and `MEMSMITH_FOLDER_USE_LOCAL_MD` have no effect on capture.

The `npm run claude-md:regenerate` and `npm run claude-md:dry-run` scripts in the source repository read the legacy SQLite database, `~/.memsmith/memsmith.db`. The `local` and `server` runtimes store new observations in Postgres, so these scripts don't see them.

## Get memory into a session

MemSmith injects relevant memory at session start and on each prompt, and the `observation_search`, `observation_context`, and `observation_get` tools read it on demand. See [Getting started](/usage/getting-started).

## Existing generated files

If an earlier version wrote `CLAUDE.md` files in your folders, each one holds a `<memsmith-context>` block. MemSmith strips that tag from captured content, so the files don't feed back into memory. Delete the block, or the file if it holds nothing else, when you no longer want it. See [Private tags and secret redaction](/usage/private-tags).
