# Memory export and import

MemSmith has no supported export or import command. The `scripts/export-memories.ts` and `scripts/import-memories.ts` files remain in the repository, but they target the retired `worker` runtime. The export script calls worker HTTP endpoints (`/api/search` and `/api/sdk-sessions/batch`) that the current server doesn't serve, so it fails against a `local` or `server` runtime.

## Alternatives

- **Share memory with a team**: Use the `server` runtime. Teammates who join the same project read the same observations. See [Hosted server](/hosted-server).
- **Move memory from an older SQLite install**: The first `local` runtime start imports `~/.memsmith/memsmith.db` into Postgres.
