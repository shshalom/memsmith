# OpenRouter provider

The `openrouter` generation provider sends each generation request to the OpenRouter chat completions API. It also works with any other OpenAI-compatible endpoint, such as a [LiteLLM gateway](/configuration/litellm-gateway), by setting a base URL.

## Get an API key

1. Sign in at [openrouter.ai](https://openrouter.ai).
2. Open [API keys](https://openrouter.ai/keys) and select **Create Key**.
3. Copy the key.

## Configure the provider

Choose one of these methods:

- Run `npx memsmith install` and choose OpenRouter. The installer saves the key and the provider.
- Select OpenRouter on the dashboard **Settings** tab. Run `memsmith status` to print the dashboard address.
- Edit `~/.memsmith/settings.json`:

```json
{
  "MEMSMITH_SERVER_PROVIDER": "openrouter",
  "MEMSMITH_OPENROUTER_API_KEY": "sk-or-v1-your-key-here",
  "MEMSMITH_SERVER_MODEL": "anthropic/claude-3.5-sonnet"
}
```

Run `memsmith restart` after you edit the file. A provider that you choose on the dashboard overrides the file.

| Setting | Default | Description |
|---------|---------|-------------|
| `MEMSMITH_SERVER_PROVIDER` | `claude` | Set to `openrouter` to use this provider. |
| `MEMSMITH_OPENROUTER_API_KEY` | none | Your OpenRouter API key. |
| `MEMSMITH_SERVER_MODEL` | `anthropic/claude-3.5-sonnet` when unset | The model ID, passed to the endpoint unchanged. |
| `MEMSMITH_OPENROUTER_BASE_URL` | OpenRouter | Base URL of an OpenAI-compatible endpoint. MemSmith appends `/chat/completions` unless the URL already ends with it. |

MemSmith resolves the API key in this order: the `MEMSMITH_OPENROUTER_API_KEY` environment variable, the value in `settings.json`, then the `OPENROUTER_API_KEY` environment variable. The base URL follows the same order with `OPENROUTER_BASE_URL` last.

Run `memsmith doctor` to confirm that the **Generation** check reports `openrouter · API key present`. The check doesn't call the endpoint.

## Request format

MemSmith sends one `POST` request for each generation job to `https://openrouter.ai/api/v1/chat/completions`, or to the endpoint that the base URL names. The request includes these headers and fields:

- `Authorization: Bearer <key>`
- `HTTP-Referer: https://github.com/shshalom/memsmith` and `X-Title: memsmith`
- A single `user` message that holds the prompt, `temperature` of `0.3`, and `max_tokens` of `4096`

## Errors and local backup

MemSmith classifies a failed request as transient, rate limited, quota exhausted, an invalid key, a parse error, or unrecoverable (for example, HTTP 400 or 404), and logs the failure.

By default, MemSmith also falls back to a local Ollama model after any failed request. For 5 minutes, jobs go to the local model first, and then MemSmith tries OpenRouter again. Set `MEMSMITH_SERVER_FALLBACK` to `none` to turn the backup off. For details, see [Configuration](/configuration).
