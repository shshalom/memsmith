# Cursor + Gemini setup

This guide sets up MemSmith in Cursor with Google's Gemini API as the generation provider. Gemini offers a free tier, which covers typical individual use.

## Step 1: Get a Gemini API key

1. Go to [Google AI Studio](https://aistudio.google.com/apikey) and sign in.
2. Click **Create API key**, and choose or create a Google Cloud project.
3. Copy the key.

## Step 2: Install MemSmith for Cursor

```bash
npx memsmith install --ide cursor --provider gemini
```

For details about what the installer does, see [Cursor integration](/cursor/index).

## Step 3: Add your API key

Add the provider and key to `~/.memsmith/settings.json`:

```json
{
  "MEMSMITH_PROVIDER": "gemini",
  "MEMSMITH_GEMINI_API_KEY": "your-api-key"
}
```

Then restart the server so it picks up the key:

```bash
memsmith restart
```

## Step 4: Verify

1. Run `memsmith status` and confirm that the server is running.
2. Open the **Dashboard** address that `memsmith status` prints.
3. Restart Cursor and start a chat. Observations appear in the dashboard as the agent works.

## Choose a model

The default model is `gemini-2.5-flash-lite`. To use a different Gemini model, set `MEMSMITH_GEMINI_MODEL`:

```json
{
  "MEMSMITH_PROVIDER": "gemini",
  "MEMSMITH_GEMINI_API_KEY": "your-api-key",
  "MEMSMITH_GEMINI_MODEL": "gemini-2.5-flash"
}
```

## Rate limiting

By default, MemSmith spaces Gemini requests to stay within free-tier limits. Processing can be slower, but observations aren't lost. If billing is enabled on your Google Cloud project and you want to send requests without spacing, set `MEMSMITH_GEMINI_RATE_LIMITING_ENABLED` to `false`.

## Troubleshooting

### "Gemini API key not configured"

Confirm that `~/.memsmith/settings.json` contains `MEMSMITH_PROVIDER` set to `gemini` and a non-empty `MEMSMITH_GEMINI_API_KEY`, then run `memsmith restart`.

### Rate limit errors (HTTP 429)

You're over the free-tier limit. Wait a few minutes, enable billing on your Google Cloud project, or switch to another provider.

### Observations aren't generated

Check the server logs in `~/.memsmith/logs/` for Gemini API errors, and run `memsmith doctor`.

## Switch providers

To switch providers, change `MEMSMITH_PROVIDER` to `claude`, `openrouter`, or `ollama`, set that provider's key if it needs one, and run `memsmith restart`.
