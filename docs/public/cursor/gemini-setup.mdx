# Cursor + Gemini setup

This guide sets up MemSmith in Cursor with Google's Gemini API as the generation provider. Google AI Studio offers a free tier of the Gemini API, subject to Google's current limits.

## Step 1: Get a Gemini API key

1. Go to [Google AI Studio](https://aistudio.google.com/apikey) and sign in.
2. Click **Create API key**, and choose or create a Google Cloud project.
3. Copy the key.

## Step 2: Install MemSmith for Cursor

```bash
npx memsmith install --ide cursor --provider gemini
```

In an interactive terminal, the installer prompts for your API key. It saves `MEMSMITH_SERVER_PROVIDER`, `MEMSMITH_SERVER_MODEL`, and `MEMSMITH_GEMINI_API_KEY` to `~/.memsmith/settings.json`. If you skip the prompt, or you run the installer without a terminal, the installer warns that Gemini needs an API key and you complete step 3.

For details about what the installer does, see [Cursor integration](/cursor/index).

## Step 3: Add your API key (if the installer did not)

Add the provider and key to `~/.memsmith/settings.json`:

```json
{
  "MEMSMITH_SERVER_PROVIDER": "gemini",
  "MEMSMITH_GEMINI_API_KEY": "your-api-key"
}
```

Then restart the server so it picks up the key:

```bash
memsmith restart
```

## Step 4: Verify

1. Run `memsmith status` and confirm that the server is running.
2. Open the address on the `Dashboard:` line of `memsmith status`.
3. Restart Cursor and start a chat. Observations appear in the dashboard as the agent works.

## Choose a model

The default model is `gemini-2.5-flash`. To use a different Gemini model, set `MEMSMITH_SERVER_MODEL`:

```json
{
  "MEMSMITH_SERVER_PROVIDER": "gemini",
  "MEMSMITH_GEMINI_API_KEY": "your-api-key",
  "MEMSMITH_SERVER_MODEL": "gemini-2.5-flash-lite"
}
```

## Troubleshooting

### Observations aren't generated and the log reports a missing key

Confirm that `~/.memsmith/settings.json` contains `MEMSMITH_SERVER_PROVIDER` set to `gemini` and a non-empty `MEMSMITH_GEMINI_API_KEY`, then run `memsmith restart`.

### Rate limit errors (HTTP 429)

You're over your Gemini quota. Wait a few minutes, enable billing on your Google Cloud project, or switch to another provider.

### Observations aren't generated for another reason

Check the server logs in `~/.memsmith/logs/` for Gemini API errors, and run `memsmith doctor`.

## Switch providers

To switch providers, change `MEMSMITH_SERVER_PROVIDER` to `claude`, `openrouter`, or `ollama`, set that provider's key if it needs one, and run `memsmith restart`.
