# Cursor + OpenRouter setup

This guide sets up MemSmith in Cursor with OpenRouter as the generation provider. OpenRouter gives you access to many models, including free ones, through a single API key.

## Step 1: Get an OpenRouter API key

1. Go to [OpenRouter](https://openrouter.ai) and sign in.
2. Open [API Keys](https://openrouter.ai/keys) and click **Create Key**.
3. Copy the key.

## Step 2: Install MemSmith for Cursor

```bash
npx memsmith install --ide cursor --provider openrouter
```

In an interactive terminal, the installer prompts for your API key. It saves `MEMSMITH_SERVER_PROVIDER`, `MEMSMITH_SERVER_MODEL`, and `MEMSMITH_OPENROUTER_API_KEY` to `~/.memsmith/settings.json`. If you skip the prompt, or you run the installer without a terminal, the installer warns that OpenRouter needs an API key and you complete step 3.

For details about what the installer does, see [Cursor integration](/cursor/index).

## Step 3: Add your API key (if the installer did not)

Add the provider and key to `~/.memsmith/settings.json`:

```json
{
  "MEMSMITH_SERVER_PROVIDER": "openrouter",
  "MEMSMITH_OPENROUTER_API_KEY": "your-api-key"
}
```

Then restart the server so it picks up the key:

```bash
memsmith restart
```

## Step 4: Verify

1. Run `memsmith status` and confirm that the server is running.
2. Open the **Dashboard** address that `memsmith status` prints.
3. Restart Cursor and start a chat. Observations appear in the dashboard as the agent works.

## Choose a model

The default model is `anthropic/claude-3.5-sonnet`, which is a paid model. To use another model, set `MEMSMITH_SERVER_MODEL` to its OpenRouter ID. Free models have a `:free` suffix; see the [model list](https://openrouter.ai/models).

```json
{
  "MEMSMITH_SERVER_PROVIDER": "openrouter",
  "MEMSMITH_OPENROUTER_API_KEY": "your-api-key",
  "MEMSMITH_SERVER_MODEL": "google/gemini-2.5-flash"
}
```

## Custom OpenAI-compatible endpoints

The `openrouter` provider is an OpenAI-compatible client. To point it at another endpoint that supports the OpenAI `/chat/completions` API, such as DeepSeek, LM Studio, or a gateway, set `MEMSMITH_OPENROUTER_BASE_URL`. MemSmith sends the model ID in `MEMSMITH_SERVER_MODEL` unchanged.

If `MEMSMITH_OPENROUTER_BASE_URL` is empty, requests go to OpenRouter. If you set it, MemSmith appends `/chat/completions` to the base URL, or uses the URL as is when it already ends in `/chat/completions`. The `OPENROUTER_BASE_URL` environment variable is a fallback.

The provider requires a non-empty API key even for endpoints that don't check one.

### DeepSeek

```json
{
  "MEMSMITH_SERVER_PROVIDER": "openrouter",
  "MEMSMITH_OPENROUTER_BASE_URL": "https://api.deepseek.com",
  "MEMSMITH_SERVER_MODEL": "deepseek-chat",
  "MEMSMITH_OPENROUTER_API_KEY": "YOUR_DEEPSEEK_API_KEY"
}
```

### LM Studio (local model)

LM Studio exposes an OpenAI-compatible server. Set any placeholder value as the API key, and set the model ID of a model that you loaded.

```json
{
  "MEMSMITH_SERVER_PROVIDER": "openrouter",
  "MEMSMITH_OPENROUTER_BASE_URL": "http://localhost:1234/v1",
  "MEMSMITH_SERVER_MODEL": "your-local-model-id",
  "MEMSMITH_OPENROUTER_API_KEY": "placeholder"
}
```

## Cost management

OpenRouter charges per token for paid models. Choose a `:free` model, check usage in the [OpenRouter dashboard](https://openrouter.ai/activity), and set spending limits in your OpenRouter account.

## Troubleshooting

### Observations aren't generated and the log reports a missing key

Confirm that `~/.memsmith/settings.json` contains `MEMSMITH_SERVER_PROVIDER` set to `openrouter` and a non-empty `MEMSMITH_OPENROUTER_API_KEY`, then run `memsmith restart`.

### Model not found

Check the model ID on [OpenRouter Models](https://openrouter.ai/models). Paid models need account credits.

### Rate limits

OpenRouter rate limits vary by model and account. Wait and retry, or choose a less busy model.

### API errors

Check the server logs in `~/.memsmith/logs/`. Common causes are an invalid key, missing credits, or a model that's temporarily unavailable.

## Switch providers

To switch providers, change `MEMSMITH_SERVER_PROVIDER` to `claude`, `gemini`, or `ollama`, set that provider's key if it needs one, and run `memsmith restart`.
