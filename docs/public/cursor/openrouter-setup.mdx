# Cursor + OpenRouter setup

This guide sets up MemSmith in Cursor with OpenRouter as the generation provider. OpenRouter gives you access to many models, including free ones, through a single API key.

## Step 1: Get an OpenRouter API key

1. Go to [OpenRouter](https://openrouter.ai) and sign in.
2. Open [API Keys](https://openrouter.ai/keys) and click **Create Key**.
3. Copy the key.

## Step 2: Install MemSmith for Cursor

```bash
npx memsmith install --ide cursor --provider openrouter
```

For details about what the installer does, see [Cursor integration](/cursor/index).

## Step 3: Add your API key

Add the provider and key to `~/.memsmith/settings.json`:

```json
{
  "MEMSMITH_SERVER_PROVIDER": "openrouter",
  "MEMSMITH_OPENROUTER_API_KEY": "your-api-key"
}
```

Then restart the server so it picks up the key:

```bash
memsmith restart
```

## Step 4: Verify

1. Run `memsmith status` and confirm that the server is running.
2. Open the **Dashboard** address that `memsmith status` prints.
3. Restart Cursor and start a chat. Observations appear in the dashboard as the agent works.

## Choose a model

The default model is `xiaomi/mimo-v2-flash:free`. To use another model, set `MEMSMITH_OPENROUTER_MODEL` to its OpenRouter ID. Free models have a `:free` suffix; see the [model list](https://openrouter.ai/models).

```json
{
  "MEMSMITH_SERVER_PROVIDER": "openrouter",
  "MEMSMITH_OPENROUTER_API_KEY": "your-api-key",
  "MEMSMITH_OPENROUTER_MODEL": "google/gemini-2.5-flash"
}
```

## Custom OpenAI-compatible endpoints

The OpenRouter provider is a generic OpenAI-compatible client. Set `MEMSMITH_OPENROUTER_BASE_URL` to point it at any endpoint that speaks the OpenAI `/chat/completions` API — DeepSeek, a local LM Studio server, or any custom gateway. The model id you set in `MEMSMITH_OPENROUTER_MODEL` is sent verbatim.

<Info>
**Base URL resolution:** When `MEMSMITH_OPENROUTER_BASE_URL` is empty (default), requests go to OpenRouter unchanged. When set, memsmith POSTs to `<base_url>/chat/completions` — you can supply either a base like `https://api.deepseek.com/v1` (the `/chat/completions` path is appended automatically) or a full `.../chat/completions` URL (used verbatim). Trailing slashes are normalized. The environment variable `OPENROUTER_BASE_URL` is honored as a fallback.
</Info>

### DeepSeek

```json
{
  "MEMSMITH_SERVER_PROVIDER": "openrouter",
  "MEMSMITH_OPENROUTER_BASE_URL": "https://api.deepseek.com",
  "MEMSMITH_OPENROUTER_MODEL": "deepseek-chat",
  "MEMSMITH_OPENROUTER_API_KEY": "YOUR_DEEPSEEK_API_KEY"
}
```

### LM Studio (local model)

LM Studio exposes an OpenAI-compatible server. No API key is required for local use, and you can use any model id you have loaded.

```json
{
  "MEMSMITH_SERVER_PROVIDER": "openrouter",
  "MEMSMITH_OPENROUTER_BASE_URL": "http://localhost:1234/v1",
  "MEMSMITH_OPENROUTER_MODEL": "your-local-model-id"
}
```

### Generic custom endpoint

Any OpenAI-compatible gateway works the same way:

```json
{
  "MEMSMITH_SERVER_PROVIDER": "openrouter",
  "MEMSMITH_OPENROUTER_BASE_URL": "https://my-gateway.example.com/v1",
  "MEMSMITH_OPENROUTER_MODEL": "model-id",
  "MEMSMITH_OPENROUTER_API_KEY": "YOUR_KEY"
}
```

## Cost management

OpenRouter charges per token. To manage costs:

1. **Use free models:** Several high-quality free models are available
2. **Monitor usage:** Check your [OpenRouter dashboard](https://openrouter.ai/activity)
3. **Set spending limits:** Configure limits in OpenRouter settings

<Warning>
**Cost awareness:** Unlike Gemini's free tier, OpenRouter paid models charge per request. Monitor your usage if using paid models.
</Warning>

## Troubleshooting

### "OpenRouter API key not configured"

Confirm that `~/.memsmith/settings.json` contains `MEMSMITH_SERVER_PROVIDER` set to `openrouter` and a non-empty `MEMSMITH_OPENROUTER_API_KEY`, then run `memsmith restart`.

### Model not found

Check the model ID on [OpenRouter Models](https://openrouter.ai/models). Paid models need account credits.

### Rate limits

OpenRouter rate limits vary by model and account. Wait and retry, or choose a less busy model.

### API errors

Check the server logs in `~/.memsmith/logs/`. Common causes are an invalid key, missing credits, or a model that's temporarily unavailable.

## Switch providers

To switch providers, change `MEMSMITH_SERVER_PROVIDER` to `claude`, `gemini`, or `ollama`, set that provider's key if it needs one, and run `memsmith restart`.
