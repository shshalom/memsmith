# MemSmith

**Persistent, local-first memory for Claude Code, with optional shared team memory.**

MemSmith captures what your agent does in each session, turns it into searchable observations, and brings the relevant ones back in later sessions. Claude keeps its knowledge of a project after a session ends.

## Quick start

To install, run:

```bash
npx memsmith install
```

Or install from the plugin marketplace inside Claude Code:

```bash
/plugin marketplace add shshalom/memsmith
/plugin install memsmith@shshalom
```

Restart Claude Code. Memory injection starts on your second session in a project.

## Key features

- **Persistent memory**: Context survives across sessions.
- **Semantic search**: Postgres full-text search plus pgvector embeddings.
- **Memory tools**: `observation_search`, `observation_get`, `observation_context`, and `note_add` through MCP.
- **User notes**: Ask Claude to remember something, and it saves a note that ranks first in search.
- **Local or team runtime**: Run everything on your machine, or share memory through a team server.
- **Modes**: Code mode, a lighter chill variant, and 29 language variants.
- **Dashboard**: Browse observations, notes, and generation status.
- **Privacy control**: Wrap content in `<private>` tags to keep it out of memory.

## How it works

```
Session start  → Inject recent and relevant observations
Your prompt    → Inject the most relevant memory for that prompt
Tool use       → Hooks send activity to the MemSmith server
Generation     → Your provider turns activity into observations, stored in Postgres
Claude stops   → The server summarizes the session
```

**Core components:**

1. **Plugin hooks**: SessionStart, UserPromptSubmit, PreToolUse, PostToolUse, and Stop.
2. **MemSmith server**: Listens on `127.0.0.1` at `38877 + (your user ID % 100)`. It stores observations, runs generation, and serves search, context, and the dashboard.
3. **Postgres with pgvector**: The local runtime runs an embedded Postgres in `~/.memsmith/pgdata`. The team runtime connects to a remote Postgres.
4. **Local embedder**: Computes embeddings on your machine (all-MiniLM-L6-v2), so semantic search needs no extra API key.
5. **MCP server**: Exposes the memory tools and the `smart_*` code exploration tools.

For details, see [Architecture overview](/architecture/overview).

## System requirements

- **Node.js** 20.12 or later
- **Bun** 1.0 or later (installed automatically if missing)
- **uv** (installed automatically if missing)
- **Claude Code** or another supported IDE (Cursor, Windsurf, OpenCode, Codex CLI, Antigravity CLI, and others)

You don't need Docker or a separate database.
