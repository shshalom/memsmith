# Antigravity CLI setup

MemSmith gives Antigravity CLI (`agy`) persistent memory across sessions. Antigravity CLI reuses the `~/.gemini/` configuration tree of Gemini CLI, so MemSmith installs its hooks there. The hooks send tool use, agent responses, and prompts to the MemSmith server. The server turns them into observations with your generation provider and stores them in Postgres.

<Note>
Antigravity CLI is a different product from the Antigravity desktop IDE (the `antigravity` binary). The installer detects Antigravity CLI when `agy` is in your `PATH` or the `~/.gemini/antigravity` directory exists.
</Note>

## Prerequisites

- Antigravity CLI (`agy`)
- Node.js 20.12 or later

## Install

Run the installer with the Antigravity identifier:

```bash
npx memsmith install --ide antigravity
```

The installer does the following:

1. Merges seven MemSmith hooks into `~/.gemini/settings.json`.
2. Adds a `<memsmith-context>` placeholder section to `~/.gemini/GEMINI.md`.
3. Registers the MemSmith MCP server in both `~/.gemini/antigravity/mcp_config.json` and `~/.gemini/config/mcp_config.json`. MemSmith writes both files because the install can't determine which one `agy` reads.
4. Writes a context placeholder to `~/.agents/rules/memsmith-context.md`.
5. Starts the local MemSmith server, unless you pass `--no-auto-start`.

The installer creates `~/.gemini` if it doesn't exist. To pick the generation provider without the interactive prompt, add `--provider`. See [Configuration](/configuration) and [Gemini provider](/usage/gemini-provider).

To install or check only the Antigravity CLI integration, run `npx memsmith antigravity-cli install`, `npx memsmith antigravity-cli status`, or `npx memsmith antigravity-cli uninstall`.

## Verify the installation

1. Run `npx memsmith status` and confirm that the server is running.
2. Run `npx memsmith antigravity-cli status` to check the hooks and MCP entries.
3. Restart `agy`, work for a while, and open the address on the `Dashboard:` line of `npx memsmith status`. New observations appear there.

## Hooks

| Antigravity CLI hook | MemSmith event | Purpose |
|------|-----------------|---------|
| `SessionStart` | `context` | Injects memory context into the session. |
| `BeforeAgent` | `session-init` | Captures the user prompt. |
| `AfterAgent` | `observation` | Records the agent response. |
| `BeforeTool` | `observation` | Records the tool call before it runs. |
| `AfterTool` | `observation` | Records the tool result. |
| `Notification` | `observation` | Records system events, such as permission requests. |
| `PreCompress` | `summarize` | Captures a session summary before compression. |

MemSmith doesn't register `SessionEnd`. The server completes sessions itself.

## MCP tools

The MemSmith MCP server gives the agent `observation_search`, `observation_get`, `observation_context`, `note_add`, and the `smart_*` code tools.

## Troubleshooting

### Hooks don't fire

1. Check that `~/.gemini/settings.json` contains entries named `memsmith` under hooks such as `SessionStart` and `AfterTool`.
2. Restart `agy`.
3. Run `npx memsmith install --ide antigravity` again.

### The server isn't running

Run `npx memsmith doctor --fix`. Server logs are in `~/.memsmith/logs/`.

### No context appears at session start

1. Run `npx memsmith status` and confirm that the server is running.
2. Confirm that at least one earlier session produced observations.
3. Confirm that your generation provider and its API key are set in `~/.memsmith/settings.json`.

## Uninstall

To remove only the Antigravity CLI integration, run:

```bash
npx memsmith antigravity-cli uninstall
```

`npx memsmith uninstall` removes every MemSmith integration, including this one. The Antigravity CLI uninstall removes the MemSmith hooks from `~/.gemini/settings.json`, the context section from `~/.gemini/GEMINI.md` and `~/.agents/rules/memsmith-context.md`, and the MemSmith entry from both MCP configuration files. It leaves other content in those files unchanged.
