# Configuration

MemSmith reads settings from four places. To see every setting and its default, see the [settings reference](/settings-reference).

## Where settings come from

| Source | Location | Use it for |
|--------|----------|------------|
| Environment variable | The shell or process that starts the session or server | A value for one session, such as `MEMSMITH_ACCESS=read claude`. |
| Settings file | `~/.memsmith/settings.json` | A default for every session. MemSmith creates the file with defaults on first run and sets its mode to `0600`. |
| Key file | `~/.memsmith/.env` | The Anthropic API key that the installer saves as `ANTHROPIC_API_KEY`. |
| Dashboard | The **Settings** tab of the [dashboard](/dashboard) | A subset of the generation and search settings, saved as team overrides. |

An environment variable with the same name as a setting overrides `settings.json`. For the settings on the dashboard **Settings** tab, a value that you save on the dashboard overrides both. To use a different directory for all MemSmith files, set `MEMSMITH_DATA_DIR`.

## Change a setting

1. Open `~/.memsmith/settings.json`. Keep it valid JSON with one flat object.
2. Add or change the key, for example `"MEMSMITH_LOG_LEVEL": "DEBUG"`.
3. Run `memsmith restart`.

The hooks read `settings.json` each time they run, so hook settings such as `MEMSMITH_ACCESS`, `MEMSMITH_HOOKS_DISABLED`, and `MEMSMITH_ACTOR` apply to the next hook without a restart. The MCP server and the transcript watcher read them when they start, so restart the Claude Code session to apply a change there.

The installer asks for the generation provider and writes `MEMSMITH_SERVER_PROVIDER` and `MEMSMITH_SERVER_MODEL`. To change them later, rerun `npx memsmith install`, edit the file, or choose a provider on the dashboard.

## Check the effective configuration

To see the effective memory access, the turned-off hook features, and the generation provider that the running server resolves, run `memsmith doctor`. For the server address and the project of the current folder, run `memsmith status`.

## Troubleshoot configuration

### A change has no effect

1. Confirm that `~/.memsmith/settings.json` is valid JSON.
2. Confirm that no environment variable with the same name overrides it. Hooks started by Claude Code use the environment of the Claude Code process, which can differ from your shell.
3. If the setting is on the dashboard **Settings** tab, check that a saved dashboard value doesn't override it.
4. Run `memsmith restart`.

### The server port is in use

Set `MEMSMITH_SERVER_URL` to `http://127.0.0.1:<free-port>` in `settings.json`, then run `memsmith restart`.
