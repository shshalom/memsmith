# Configuration

## Settings file

MemSmith reads its settings from `~/.memsmith/settings.json` and creates the file with defaults on first run. An environment variable with the same name overrides the file. After you change a setting, run `memsmith restart`.

## Generation provider

| Setting | Default | Description |
|---------|---------|-------------|
| `MEMSMITH_PROVIDER` | `claude` | Generation provider: `claude`, `gemini`, `openrouter`, or `ollama`. |
| `MEMSMITH_MODEL` | `claude-haiku-4-5-20251001` | Claude model, when the provider is `claude`. |
| `MEMSMITH_CLAUDE_AUTH_METHOD` | `subscription` | Claude authentication: `subscription`, `api-key`, or `gateway`. |
| `MEMSMITH_GEMINI_API_KEY` | empty | Gemini API key. [Get a key](https://aistudio.google.com/apikey). |
| `MEMSMITH_GEMINI_MODEL` | `gemini-2.5-flash-lite` | Gemini model. |
| `MEMSMITH_GEMINI_RATE_LIMITING_ENABLED` | `true` | Spaces Gemini requests to stay within free-tier limits. |
| `MEMSMITH_OPENROUTER_API_KEY` | empty | OpenRouter API key. [Get a key](https://openrouter.ai/keys). |
| `MEMSMITH_OPENROUTER_MODEL` | `xiaomi/mimo-v2-flash:free` | OpenRouter model ID. |
| `MEMSMITH_OPENROUTER_BASE_URL` | empty | Any OpenAI-compatible endpoint. Empty means OpenRouter. |
| `MEMSMITH_OPENROUTER_SITE_URL` | empty | Optional site URL sent to OpenRouter. |
| `MEMSMITH_OPENROUTER_APP_NAME` | `memsmith` | App name sent to OpenRouter. |
| `MEMSMITH_OLLAMA_URL` | `http://localhost:11434/v1` | Ollama's OpenAI-compatible base URL. |
| `MEMSMITH_OLLAMA_MODEL` | `qwen2.5:14b` | Ollama model. |

For provider guides, see [Gemini](/usage/gemini-provider) and [OpenRouter](/usage/openrouter-provider).

### Claude models

When the provider is `claude`, `npx memsmith install` asks for a model and saves it as `MEMSMITH_MODEL`:

| Value | Notes |
|-------|-------|
| `claude-haiku-4-5-20251001` | Default. Fast and low cost. |
| `claude-sonnet-4-6` | Balanced quality and cost. |
| `claude-opus-4-7` | Highest quality and cost. |

### Claude gateway

Gateway credentials live in `~/.memsmith/.env`, not in `settings.json`:

| Variable | Description |
|----------|-------------|
| `ANTHROPIC_BASE_URL` | A LiteLLM or other Anthropic-compatible gateway URL. |
| `ANTHROPIC_AUTH_TOKEN` | Optional gateway key. |
| `ANTHROPIC_API_KEY` | A direct Anthropic API key. Usually omitted in gateway mode. |

For details, see [LiteLLM gateway](/configuration/litellm-gateway).

## Runtime and server

| Setting | Default | Description |
|---------|---------|-------------|
| `MEMSMITH_RUNTIME` | `local` | `local` runs an embedded Postgres on this machine. `server` connects to a team's MemSmith server. |
| `MEMSMITH_SERVER_URL` | `http://127.0.0.1:<38877 + uid % 100>` | Address of the MemSmith server. The CLI and hooks read it from here. |
| `MEMSMITH_SERVER_API_KEY` | empty | API key the hooks send to the server. The installer sets it. |
| `MEMSMITH_SERVER_PROJECT_ID` | empty | Default project ID for the server runtime. |
| `MEMSMITH_DATA_DIR` | `~/.memsmith` | Root directory for settings, logs, and the embedded Postgres data. |
| `MEMSMITH_LOG_LEVEL` | `INFO` | Log verbosity: `DEBUG`, `INFO`, `WARN`, `ERROR`, or `SILENT`. |

The embedded Postgres listens on port `55433`. To change it, set the `MEMSMITH_LOCAL_PG_PORT` environment variable.

## Capture

| Setting | Default | Description |
|---------|---------|-------------|
| `MEMSMITH_MODE` | `code` | Mode profile that controls observation types and language. See [Modes & languages](/modes). |
| `MEMSMITH_SKIP_TOOLS` | `ListMcpResourcesTool,SlashCommand,Skill,TodoWrite,AskUserQuestion` | Tools that are never recorded. |
| `MEMSMITH_EXCLUDED_PROJECTS` | empty | Comma-separated glob patterns for project paths that are never captured. |
| `MEMSMITH_INCLUDED_PROJECTS` | empty | Comma-separated glob patterns. When set, only matching projects are captured. |

### Mode examples

```json
{
  "MEMSMITH_MODE": "code--es"
}
```

```json
{
  "MEMSMITH_MODE": "code--chill"
}
```

## Context injection

| Setting | Default | Description |
|---------|---------|-------------|
| `MEMSMITH_CONTEXT_OBSERVATIONS` | `50` | Maximum observations injected at session start. |
| `MEMSMITH_CONTEXT_SESSION_COUNT` | `10` | Number of recent sessions that session-start context draws from. |
| `MEMSMITH_SEMANTIC_INJECT` | `true` | Injects the most relevant memory on every prompt. |
| `MEMSMITH_SEMANTIC_INJECT_LIMIT` | `5` | Observations injected per prompt. |
| `MEMSMITH_RETRIEVAL_ENFORCEMENT` | `hard` | `hard` blocks some discovery tools until Claude consults memory on the topic. `soft` only injects. |
| `MEMSMITH_USER_NOTE_BOOST` | `true` | Ranks user notes ahead of other observations in search results. |
| `MEMSMITH_WELCOME_HINT_ENABLED` | `true` | Shows a hint during your first session in a project. |

## Team memory

| Setting | Default | Description |
|---------|---------|-------------|
| `MEMSMITH_TEAM_INJECT` | `false` | Injects team memory at session start. |
| `MEMSMITH_TEAM_SERVER_URL` | empty | Team server that team memory is read from. |
| `MEMSMITH_TEAM_API_KEY` | empty | Read-scoped key for the team server. |

## Folder context files

MemSmith can generate `CLAUDE.md` files in your project folders with recent activity. This feature is off by default.

| Setting | Default | Description |
|---------|---------|-------------|
| `MEMSMITH_FOLDER_CLAUDEMD_ENABLED` | `false` | Generates folder `CLAUDE.md` files. |
| `MEMSMITH_FOLDER_USE_LOCAL_MD` | `false` | Writes `CLAUDE.local.md` instead of `CLAUDE.md`. |

For details, see [Folder context files](/usage/folder-context).

## Telemetry

MemSmith sends no telemetry unless you set `MEMSMITH_TELEMETRY_KEY`. For details, see [Telemetry](/telemetry).

## Server management

The server starts automatically at the beginning of a session. To manage it yourself, run `memsmith start`, `memsmith stop`, `memsmith restart`, or `memsmith status`. To diagnose and repair the install, run `memsmith doctor --fix`.

## Troubleshooting configuration

### A change has no effect

1. Confirm that `~/.memsmith/settings.json` is valid JSON.
2. Confirm that no environment variable with the same name overrides it.
3. Run `memsmith restart`.

### The server port is in use

Set `MEMSMITH_SERVER_URL` to `http://127.0.0.1:<free-port>` and run `memsmith restart`.
