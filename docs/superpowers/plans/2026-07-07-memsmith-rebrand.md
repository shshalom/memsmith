# MemSmith Rebrand Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rename the product claude-mem → MemSmith with zero shared identifiers (clean break), so it can run independently of the installed claude-mem and be dogfooded.

**Architecture:** Ordered, form-specific, keep-list-excluding string transforms applied in scoped passes by area (source → manifests/config → scripts/hooks → tests → docs), then regenerate bundles and verify. Pure rename — NO behavior change.

**Tech Stack:** TypeScript, bun test, esbuild bundles. No new deps.

## Global Constraints

- **One-word style** everywhere: `memsmith` (kebab/snake/pkg/binary), `MEMSMITH_` (env), `MemSmith` (Pascal/title), `memSmith` (camel). NOT two words, no `mem-smith`/`MEM_SMITH_`.
- **Data dir:** `~/.claude-mem` → `~/.memsmith`.
- **Repo/owner:** `github.com/thedotmack/claude-mem` → `github.com/shshalom/memsmith`; marketplace owner/id `thedotmack` → `shshalom` (owner) / `memsmith` (plugin id).
- **MCP:** the `plugin/.mcp.json` server key → `memsmith` so tools surface as `mcp__memsmith__*`.
- **KEEP-LIST — never rename** (external, not our product): `claude-code`, `claude-agent`, `claude-agent-sdk`, `@anthropic-ai/*`, `claude.ai`, `anthropic`, `@huggingface/*`, `@modelcontextprotocol/*`, all dependency package names. The `description` "for Claude Code" and the `claude-code` keyword stay.
- **Transform order (most-specific first, kebab LAST):** (1) `CLAUDE_MEM_`→`MEMSMITH_` (2) `.claude-mem`→`.memsmith` (3) `thedotmack/claude-mem`→`shshalom/memsmith` & standalone `thedotmack`→`shshalom` (4) `ClaudeMem`→`MemSmith` (5) `claudeMem`→`memSmith` (6) `claude_mem`→`memsmith` (7) `Claude-Mem`/`Claude Mem`→`MemSmith` (8) `claude-mem`→`memsmith` — each pass MUST NOT match strings containing `claude-code`/`claude-agent`.
- **Bundles** (`plugin/scripts/*.cjs`) are regenerated by `npm run build`, never hand-edited; committed with their task.
- **No behavior change** — this is a rename. If a "rename" would change logic, stop and flag it.
- **Verification gates** (run at the end, Task 7): `npm run build` exit 0 + zero tracked bundle drift; `tsc --noEmit` 0 errors; full suite parity with pre-rename baseline (2479/0 with test DB on :55432); grep sweep shows zero product refs outside the keep-list.
- **10 mixed files** carry BOTH product and keep-list refs — highest care: `src/shared/dependency-health.ts`, `src/shared/find-claude-executable.ts`, `src/cli/handlers/context.ts`, `src/sdk/hardened-options.ts`, `src/npx-cli/index.ts`, `src/npx-cli/install/setup-runtime.ts`, `src/npx-cli/commands/install.ts`, `src/build/hook-shell-template.ts`, `src/npx-cli/commands/telemetry.ts`, `src/services/worker-service.ts`.

## Task 1: Rename `src/` (source of truth)

**Files:** all of `src/**` (~143 files touch the string). Special care on the 10 mixed files listed in Global Constraints.

- [ ] **Step 1: Apply the ordered transforms to src/ only**

Use a script that runs the 8 transforms IN ORDER, each with a keep-list guard. Example (per-file, skipping binary):

```bash
cd /Users/shwaits/Workspace/team-agent-memory/research/repos/claude-mem
FILES=$(grep -rIl 'claude[-_]mem\|claudeMem\|ClaudeMem\|CLAUDE_MEM\|Claude Mem\|Claude-Mem' src)
for f in $FILES; do
  perl -i -pe '
    s/CLAUDE_MEM_/MEMSMITH_/g;
    s/\.claude-mem\b/.memsmith/g;
    s{thedotmack/claude-mem}{shshalom/memsmith}g;
    s/\bthedotmack\b/shshalom/g;
    s/ClaudeMem/MemSmith/g;
    s/claudeMem/memSmith/g;
    s/claude_mem/memsmith/g;
    s/Claude-Mem/MemSmith/g;
    s/Claude Mem/MemSmith/g;
    # kebab LAST, and never inside claude-code / claude-agent
    s/(?<!claude-)claude-mem(?!-agent)/memsmith/g unless /claude-code|claude-agent/;
    s/claude-mem/memsmith/g if !/claude-code|claude-agent/;
  ' "$f"
done
```
NOTE: the kebab rule must not fire on lines containing `claude-code`/`claude-agent`. For the 10 mixed files, after the pass, MANUALLY verify each `claude-` occurrence: `memsmith` where it was our product, untouched where it's `claude-code`/`claude-agent-sdk`.
