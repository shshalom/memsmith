# L0–L3 Tiered Injection Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Fit more relevant team memory into a fixed injection budget by rendering lower-ranked observations at reduced detail (title → +facts → +why → full) instead of dropping them.

**Architecture:** New pure module `src/server/retrieval/tiering.ts` renders an observation at a chosen tier from its structured metadata and greedily assigns tiers to a ranked set to fit a char budget. `buildInjectionBlock` (inject.ts) is rewritten to tier-then-position instead of drop-whole-items. Deterministic, no LLM, no schema change. An env off-switch restores the old behavior.

**Tech Stack:** TypeScript, bun:test (pure unit tests, no DB).

## Global Constraints

- Deterministic, no LLM call — tiers are pure field selection from existing `metadata`.
- No schema change; tiers derive from metadata keys already written by generation: `title`, `subtitle`, `facts` (string[]), `narrative`, `why`.
- Tiering MUST NOT change ordering (only per-item detail); positioning still runs after.
- Tiering MUST NEVER throw — malformed/missing metadata degrades gracefully, then the whole builder falls back to pre-tiering behavior on any unexpected error.
- Off-switch: `CLAUDE_MEM_TIERING` default `on`; `0`/`off` restores whole-item-drop.
- `buildInjectionBlock`'s public signature and return type are UNCHANGED (internal swap).
- After src changes that land in a bundle, `npm run build` and commit regenerated `.cjs`. `inject.ts` is reachable from `cli/handlers/context.ts` (bundled into context-generator.cjs and/or server-service.cjs) — rebuild and commit whatever `.cjs` changes.

## Task 1: `renderAtTier` — render one observation at a tier

**Files:**
- Create: `src/server/retrieval/tiering.ts`
- Test: `tests/server/retrieval/tiering-render.test.ts`

**Interfaces:**
- Produces:
  - `type Tier = 0 | 1 | 2 | 3`
  - `type TierInput = { content: string; metadata: Record<string, unknown> }`
  - `renderAtTier(obs: TierInput, tier: Tier): string`

**Tier field mapping** (derive from metadata; fall back to a content slice when structured fields absent):
- L0: `title` (+ ` — ${subtitle}` if subtitle present). If no title → first line of `content`.
- L1: L0 + facts as `\n- fact` lines (if `facts` is a non-empty string[]). If no facts → L0.
- L2: L1 + `\nWhy: ${why}` (if `why` is a non-empty string). If no why → L1.
- L3: full `content` verbatim (today's behavior).

```ts
// src/server/retrieval/tiering.ts
// SPDX-License-Identifier: Apache-2.0
//
// Deterministic L0–L3 tiered rendering of observations for budget-constrained
// injection. No LLM: each tier is a selection of the structured fields already
// stored in observation metadata (title/subtitle/facts/why); L3 is the full
// rendered content. Graceful, never-throw degrade on missing/malformed fields.

export type Tier = 0 | 1 | 2 | 3;
export type TierInput = { content: string; metadata: Record<string, unknown> };

function str(v: unknown): string | null {
  return typeof v === 'string' && v.trim().length > 0 ? v : null;
}
function strArray(v: unknown): string[] {
  return Array.isArray(v) ? v.filter((x): x is string => typeof x === 'string' && x.length > 0) : [];
}
function firstLine(content: string): string {
  const i = content.indexOf('\n');
  return (i === -1 ? content : content.slice(0, i)).trim();
}

export function renderAtTier(obs: TierInput, tier: Tier): string {
  try {
    if (tier >= 3) return obs.content;
    const m = obs.metadata ?? {};
    const title = str(m.title);
    // L0 base: title (+ subtitle), else first line of content.
    let head: string;
    if (title) {
      const subtitle = str(m.subtitle);
      head = subtitle ? `${title} — ${subtitle}` : title;
    } else {
      head = firstLine(obs.content);
    }
    if (tier === 0) return head;

    const facts = strArray(m.facts);
    const withFacts = facts.length > 0 ? `${head}\n${facts.map(f => `- ${f}`).join('\n')}` : head;
    if (tier === 1) return withFacts;

    const why = str(m.why);
    return why ? `${withFacts}\nWhy: ${why}` : withFacts;
  } catch {
    // Never throw — fall back to full content.
    return obs.content;
  }
}
```

## Task 2: `tierToBudget` — assign tiers to a ranked set to fit a char budget

**Files:**
- Modify: `src/server/retrieval/tiering.ts`
- Test: `tests/server/retrieval/tiering-budget.test.ts`

**Interfaces:**
- Consumes: `renderAtTier`, `Tier`, `TierInput` from Task 1.
- Produces: `tierToBudget(ranked: TierInput[], opts: { maxChars: number; maxItems: number }): string[]` — returns rendered strings in RANK ORDER (index 0 = best). Greedy: cap to `maxItems`; start all at L3; while the joined length (`'\n'` sep, matching how the caller joins) exceeds `maxChars`, step down the LOWEST-ranked item still above L0 by one tier; if all are at L0 and still over, drop trailing L0 items one at a time; if a single remaining L0 still exceeds, hard-slice it to `maxChars`.

```ts
export function tierToBudget(
  ranked: TierInput[],
  opts: { maxChars: number; maxItems: number },
): string[] {
  const items = ranked.slice(0, Math.max(0, opts.maxItems));
  if (items.length === 0) return [];
  const tiers: Tier[] = items.map(() => 3);
  const joinedLen = (arr: string[]) => arr.reduce((s, x) => s + x.length, 0) + Math.max(0, arr.length - 1); // '\n' separators
  const render = () => items.map((it, i) => renderAtTier(it, tiers[i]));

  // Step down the lowest-ranked item still above L0 until we fit or all at L0.
  while (joinedLen(render()) > opts.maxChars) {
    let stepped = false;
    for (let i = items.length - 1; i >= 0; i--) {
      if (tiers[i] > 0) { tiers[i] = (tiers[i] - 1) as Tier; stepped = true; break; }
    }
    if (!stepped) break; // everyone at L0
  }

  let out = render();
  // Still over with all at L0: drop trailing items one at a time.
  while (out.length > 1 && joinedLen(out) > opts.maxChars) {
    out = out.slice(0, out.length - 1);
  }
  // A single remaining item that still overflows: hard-slice it.
  if (out.length === 1 && out[0].length > opts.maxChars) {
    out = [out[0].slice(0, opts.maxChars)];
  }
  return out;
}
```

```ts
import { positionForInjection } from './positioning.js';
import { tierToBudget, type TierInput } from './tiering.js';

export interface InjectDeps {
  hybridSearch(input: { projectId: string; teamId: string; query: string; limit?: number }): Promise<Array<{ content: string; metadata: Record<string, unknown> }>>;
}

function tieringEnabled(): boolean {
  const v = process.env.CLAUDE_MEM_TIERING;
  return v !== '0' && v !== 'off';
}

export async function buildInjectionBlock(
  deps: InjectDeps,
  input: { projectId: string; teamId: string; query: string; maxItems?: number; maxChars?: number }
): Promise<string> {
  const maxItems = input.maxItems ?? 5;
  const maxChars = input.maxChars ?? 10000;
  const rows = await deps.hybridSearch({ projectId: input.projectId, teamId: input.teamId, query: input.query, limit: maxItems * 2 });
  const visible: TierInput[] = rows.filter(r => r.metadata?.private !== true);
  if (visible.length === 0) return '';
  const header = '## Relevant team memory (review before acting)\n';
  // Reserve budget for the header + positioning bullet markers.
  const bodyBudget = Math.max(0, maxChars - header.length);

  if (tieringEnabled()) {
    try {
      const rendered = tierToBudget(visible, { maxChars: bodyBudget, maxItems });
      const body = positionForInjection(rendered, maxItems);
      if (body) return (header + body).slice(0, maxChars);
      // fall through to legacy on empty body
    } catch {
      // fall through to legacy whole-item behavior on any tiering error
    }
  }

  // Legacy whole-item-drop behavior (also the CLAUDE_MEM_TIERING=0 path).
  const contents = visible.map(r => r.content);
  for (let n = Math.min(contents.length, maxItems); n >= 1; n--) {
    const body = positionForInjection(contents.slice(0, n), maxItems);
    if (!body) continue;
    const block = header + body;
    if (block.length <= maxChars) return block;
  }
  const body = positionForInjection(contents.slice(0, 1), maxItems);
  if (!body) return '';
  return (header + body).slice(0, maxChars);
}
```
